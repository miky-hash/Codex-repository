## 1. 무엇을 만들었나

하고 싶은 **집중 시간**을 정하면 그 시간에 가까운 **실제 항공 노선**을 추천해 주고, 탑승권을 찢고 탑승하면
**지구본 위에서 비행기가 목적지로 날아가는 동안 집중**하는 앱이에요. 끝까지 집중하면 착륙 성공, 마일리지가 쌓이면 새 기종이 해금돼요.

### 처음 세운 방향 (사용자와 합의한 것)

- 웹으로 먼저 만들기 (나중에 앱)
- 실제 FocusFlight와 최대한 비슷하게: 노란 공항 칩, 검은 알약 버튼, 둥근 흰 패널, 파스텔 과목 색
- **딴짓 횟수는 세지 않기**, **좌석·체크인 없애기**, 해금은 **기종만**
- 한 화면 안에서 **흰 박스가 모양을 바꾸며 움직이는** 부드러운 전환
- 과목: 공부·국어·수학·영어·과학·사회·한국사·기타(직접 입력)

## 2. 화면 흐름

| 단계 | 화면 | 주요 기능 |
| --- | --- | --- |
| 0 | 처음 화면 | 지구본 위 공항 칩(291곳), 인사말과 위치, 오늘 집중 시간·연속 집중일. 공항을 누르면 노랗게 바뀌고 지구본이 돌아감. 아래 버튼 "인천(ICN)에서 여정 시작" → 확인 창 |
| 1 | 소요 시간 | `( 1 )h ( 30 )m` 칸을 누르면 **룰렛 휠**이 펼쳐짐(굴리는 즉시 반영). 빠른 선택 25분·50분·1:30·2:30·4:00. 0시간 0분이면 다음 버튼이 회색 |
| 2 | 출발지·도착지 | 출발지 휠 + **검색**, 도착지 목록(±10분 / ±45분 / 그 밖) + **검색**, *실제 비행시간* / *내 시간* 선택, 기종 휠(잠긴 기종은 자물쇠). 막대를 밀면 위쪽이 한 줄로 접힘 |
| 3 | 과목 | 아래에서 올라오는 시트에서 과목 선택 |
| 4 | 탑승권 | Flight time·Subject·Gate·Boarding·Arrival·Aircraft·Distance·Date. **절취선을 손가락으로 그은 만큼 실제로 찢어짐** |
| 5 | 비행 | 지구본 전체 화면, `Gate → Takeoff → Cruise → Descent → Landing`, 영어 기내 방송, 일시정지, 창 줄이기, 지도 직접 움직이기 |
| 6 | 도착·회항 | 도장, 집중 시간, 마일리지, 연속 집중일, 새 기종 해금, 환승 대기(쉬는 시간) 타이머 |
| - | 로그북 | 누적 기록, 과목별 집중 시간, 격납고(기종), 방문한 도시, 전체 비행 기록 |

도착한 공항이 **현재 위치**가 되어 다음 여정은 거기서 출발해요. 새로고침하거나 창을 닫았다 열어도 비행은 이어져요.

## 3. 규칙

| 항목 | 규칙 |
| --- | --- |
| 실제 비행시간 | 40분(지상 이동·이착륙) + 대권 거리 ÷ 780km/h, 5분 단위 반올림, 최소 30분 |
| 내 시간 | 정한 집중 시간에 맞춰 속도를 바꿔서 날아감 (속도 제한 없음) |
| 속도 | 단계별로 바뀌고, 순항 중에는 바람처럼 조금씩 오르내림. 위치는 속도를 적분해서 계산, 정확히 정해진 시간에 도착 |
| 마일리지 | **집중한 시간 1분에 8마일**(여객기 평균 약 780km/h ≈ 분당 8마일). **정한 비행시간의 절반이 지나야** 쌓이기 시작 |
| 일시정지 | 멈춘 시간은 집중 시간·진행률에서 빠지고, 도착 예정 시각이 그만큼 늦어짐 |
| 회항(비행 중단) | 로그북에 '회항'으로 기록, 착륙 성공으로 안 셈. 1분 미만이면 기록 없음 |
| 연속 집중일 | 하루 한 번 이상 착륙 성공. 자정을 넘긴 비행은 착륙한 날로 셈 |
| 기종 해금 | A220-300(기본) → A321neo 1,000mi → 787-9 5,000mi → A350-900 15,000mi → 777-300ER 30,000mi → A380-800 60,000mi |
| 노선 | 출발지에서 60km 미만인 공항은 제외 (예: 인천–김포 32km) |

### 4-6. PR #6 — 확대했을 때 지도 흔들림

지역 이름·도로는 그대로인데 지도 그림만 흔들리던 문제. MapLibre가 "지도가 멈춰 있다"고 보고 위성 사진을 픽셀 격자에 맞추는데,
앱이 카메라를 매 프레임 직접 옮겨서 사진만 1픽셀씩 끊겨 움직였음. 카메라가 움직이는 동안만 "움직이는 중"으로 알려서 해결.

## 5. 해결한 주요 문제 (원인 → 해결)

| 문제 | 원인 | 해결 |
| --- | --- | --- |
| 비행 시작 때 화면 흔들림 | 박스가 애니메이션 중일 때의 크기로 지구본 자리를 0.2초마다 다시 계산 | 박스가 도착할 자리(`dockRect`) 기준 |
| 확대하면 비행기가 멈칫 | 0.2초마다만 그림 + 인터넷 지도에서 화면 속도를 작게 계산 | 빨리 움직이면 매 프레임, 실제 반지름으로 계산 |
| 확대 시 지도 그림만 흔들림 | 멈춘 지도라고 보고 래스터를 픽셀 격자에 맞춤 | 카메라 이동 중에는 `isMoving()`을 참으로 |
| 같은 지도 다시 누르면 반투명 | 같은 스타일이라 준비 신호가 안 옴 | 같은 지도 무시 + 시간 안전장치 |
| 날짜변경선에 줄 | 셰이더에서 `fract` 사용 | 텍스처 반복(REPEAT)에 맡김 |
| 찢은 탑승권 아래 흰 배경 | 조각을 숨겨도 박스 배경이 남음 | 박스를 절취선에서 잘라내고(clip-path) 그림자는 따로 그림 |
| 비행 창 스크롤 | 내용이 창 높이보다 큼 | 압축 배치 + 넘치면 자동으로 숨김(`fitFlightPane`) |
| 예전 아이패드에서 비행기 그림자 | 캔버스 `filter` 미지원 | 검은 실루엣을 미리 만들어 둠 |

## 6. 기술 구조

### 화면 층 (아래 → 위)

1. `#sky` 별 하늘 (2D 캔버스)
2. `#earth` 내장 위성 지구본 (WebGL, NASA Blue Marble) — 인터넷 지도를 못 쓸 때
3. `#mlmap` 인터넷 지도 (MapLibre GL 5.24, 지구본 투영)
4. `#map` 항로·공항 칩·비행기 (2D 캔버스, 손가락 입력도 여기서 받음)
5. 흰 박스(`#dock`)와 버튼들

### 파일

```
flight-focus/
├── index.html      화면 구조
├── style.css       디자인
├── app.js          비행 프로필, 지구본, 타이머, 기록 등 앱 로직
├── airports.js     공항 291곳 (IATA 코드, 영어 이름, 위도·경도)
├── sw.js           기기 알림용 서비스 워커
├── world.js        세계 육지 (Natural Earth 1:110m)
├── world50.js      해안선·국경선 (Natural Earth 1:50m)
├── earth-texture.js 위성 사진 (NASA Blue Marble)
├── planes/         기종별 비행기 그림 6장
├── sounds/         기내 소음 (cabin.wav)
└── vendor/         d3-array, d3-geo, MapLibre GL JS
```

### 핵심 방식

- **지구본 카메라**: `view = {cx, cy, r, lon, lat, zoom}` 하나로 두 지도(내장·인터넷)를 같이 움직임. 인터넷 지도는 원근을 보정한 반지름으로 확대 단계를 계산
- **박스 모양 바꾸기**: 바뀌기 전·후 위치를 재서 애니메이션(FLIP 방식)
- **비행 위치**: 속도 곡선을 1,500칸으로 나눠 적분해 두고, 진행률로 위치를 찾음
- **저장**: 브라우저 `localStorage` (`focusair2.` 로 시작하는 키: log, loc, flight, prefs)
- **배포**: `main`에 합치면 `.github/workflows/pages.yml`이 `flight-focus/`를 GitHub Pages로 올림

## 10. 알려진 한계

- 웹이라서 화면이 잠기거나 다른 앱에 있으면 브라우저가 멈출 수 있어, 그동안의 알림은 늦거나 안 올 수 있음 (시간 계산은 정확히 이어짐)
- 기록은 그 기기의 브라우저에만 저장됨 (다른 기기와 공유 안 됨)
- 일부 공항은 실제로 민간 여객기가 다니지 않음 (공군 비행장, 문 닫은 공항, 북한)
- "내 시간"으로 아주 먼 곳을 짧게 날면 속도 숫자가 비현실적으로 나옴
