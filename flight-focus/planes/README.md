# 비행기 그림 넣는 곳

여기에 기종별 그림을 넣으면 앱이 자동으로 그 그림을 써요. 없으면 앱이 직접 그린 비행기를 써요.

| 파일 이름 | 기종 |
| --- | --- |
| `A220.png` | Airbus A220-300 |
| `A321.png` | Airbus A321neo |
| `B787.png` | Boeing 787-9 |
| `A350.png` | Airbus A350-900 |
| `B777.png` | Boeing 777-300ER |
| `A380.png` | Airbus A380-800 |

그림 조건
- **위에서 내려다본 모습**, **기수(앞)가 위쪽**을 향하게
- 배경은 **투명**(PNG), 비행기가 그림 세로 길이를 거의 꽉 채우게
- 크기는 512×512 정도면 충분해요
