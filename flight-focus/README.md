# 포커스 에어 (Focus Air)

Flight Focus처럼 **비행 시간 = 집중 시간**으로 공부하는 웹 앱이에요.
출발 공항과 목적지를 고르면 실제 대권 항로 거리로 비행 시간을 계산하고,
비행하는 동안 지구본 위에서 비행기가 목적지로 날아가요.

## 실행 방법

설치할 것이 없어요. `flight-focus/index.html` 파일을 브라우저로 열면 됩니다.
(글꼴만 인터넷에서 불러오고, 지도와 코드는 모두 폴더 안에 있어서 오프라인에서도 동작해요.)

## 기능

| 화면 | 하는 일 |
| --- | --- |
| 비행 예약 | 출발 공항 선택, 목적지 검색·시간 필터, 지구본에 항로 미리보기 |
| 선회 비행 | 목적지 없이 10~180분 동안 공항 상공을 선회 (25분 뽀모도로용) |
| 탑승권 | 편명·게이트·좌석 선택, "이번 비행에서 집중할 일" 입력 |
| 비행 중 | 남은 시간, 진행 막대, 고도·속도·남은 거리, 비행 단계(이륙→순항→하강) |
| 기내 기능 | 엔진 소음(브라운 노이즈), 화면 켜두기, 비상 착륙(회항 기록) |
| 도착 | 여권 도장, 집중 시간 요약, 환승 대기(5·10·15분 휴식 타이머) |
| 로그북 | 완료한 비행 수, 총 집중 시간·거리, 다녀온 공항, 비행 기록 표 |

- 도착하면 그 공항이 **현재 위치**가 되어, 다음 비행은 거기서 출발해요.
- 비행 중 3초 넘게 다른 탭·앱으로 나갔다 오면 **난기류 1회**로 기록돼요.
- 새로고침하거나 창을 닫았다 열어도 비행은 이어져요 (종료 시각 기준으로 계산).

## 비행 시간 계산

```
거리(km)  = 하버사인 공식으로 구한 두 공항 사이 대권 거리
비행 시간 = 거리 ÷ 780km/h × 60 + 20분(이착륙), 5분 단위 반올림, 최소 30분
```

예) 인천→제주 439km → 55분, 인천→나리타 약 1,250km → 1시간 55분

## 파일 구조

```
flight-focus/
├── index.html      화면 구조
├── style.css       디자인 (라이트/다크 모드)
├── app.js          타이머, 지구본, 저장 등 앱 로직
├── airports.js     공항 55곳 (IATA 코드, 위도·경도)
├── world.js        세계 지도 (Natural Earth 1:110m, 퍼블릭 도메인)
└── vendor/         d3-array, d3-geo (ISC 라이선스)
```

기록은 브라우저의 `localStorage`에만 저장돼요. 다른 기기와 공유되지 않아요.
