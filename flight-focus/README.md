# 포커스 에어 (Focus Air)

FocusFlight처럼 **집중 시간을 비행으로 바꿔 주는** 웹 앱이에요.
하고 싶은 집중 시간을 적으면 그 시간에 가까운 실제 항공편을 골라 주고,
탑승권을 찢고 탑승하면 지구본 위에서 비행기가 목적지로 날아가요.

## 실행 방법

설치할 것이 없어요. `flight-focus/index.html` 파일을 브라우저로 열면 됩니다.
(글꼴만 인터넷에서 불러오고, 지도와 코드는 모두 폴더 안에 있어서 오프라인에서도 동작해요.)

## 흐름

1. **항공권 예약**: 집중할 시간(예: 2시간 30분)과 과목(국어·수학·영어·과학·사회·한국사·기타)을 고르면,
   현재 공항에서 출발하는 항공편을 **비행시간이 가까운 순서**로 보여 줘요.
   고른 항공편은 *실제 비행시간* 또는 *내가 정한 시간* 중 하나로 날 수 있어요.
2. **탑승권**: `ICN → NRT / Flight time / Subject / Boarding / Arrival / Gate / Aircraft`.
   오른쪽 절취선의 손잡이를 끝까지 밀어 찢으면(또는 Start Flight) 출발해요.
3. **비행**: `Gate → Takeoff → Cruise → Descent → Landing` 단계가 차례로 바뀌고,
   단계마다 차임과 기내 방송이 나와요(음성은 선택). 남은 시간·남은 거리·고도·대지 속도를 보여 줘요.
   기내 소음(엔진 백색소음)과 화면 켜두기도 있어요.
4. **도착 / 회항**: 끝까지 날면 착륙 성공 도장과 마일리지를 받아요.
   중간에 "비행 중단"을 누르면 회항으로 기록되고, 날아간 거리만큼만 마일이 쌓여요. 일시정지는 없어요.
5. **로그북**: 착륙 성공 횟수, 총 집중 시간, 누적 마일리지, 연속 집중일, 과목별 집중 시간,
   방문한 도시, 격납고(기종), 전체 비행 기록.

도착한 공항이 **현재 위치**가 되어 다음 비행은 거기서 출발해요.
새로고침하거나 창을 닫았다 열어도 비행은 이어져요(종료 시각 기준으로 계산).

## 규칙

| 항목 | 규칙 |
| --- | --- |
| 실제 비행시간 | 40분(지상 이동·이착륙) + 대권 거리 ÷ 780km/h, 5분 단위 반올림 |
| 속도 | 단계별로 바뀌고, 순항 중에는 바람처럼 조금씩 오르내림. 위치는 이 속도를 적분해서 계산하고, 정확히 정해진 시간에 도착하도록 맞춤 |
| 마일리지 | 비행한 거리(km) × 0.621 |
| 연속 집중일 | 하루 한 번 이상 착륙 성공. 자정을 넘긴 비행은 착륙한 날로 셈 |
| 기종 해금 | A220-300(기본) → A321neo 1,000mi → 787-9 5,000mi → A350-900 15,000mi → 777-300ER 30,000mi → A380-800 60,000mi |

예) 인천→나리타 약 1,258km → 실제 비행시간 02:15

## 파일 구조

```
flight-focus/
├── index.html      화면 구조
├── style.css       디자인 (라이트/다크 모드)
├── app.js          비행 프로필, 지구본, 타이머, 기록 등 앱 로직
├── airports.js     공항 55곳 (IATA 코드, 위도·경도)
├── world.js        세계 지도 (Natural Earth 1:110m, 퍼블릭 도메인)
└── vendor/         d3-array, d3-geo (ISC 라이선스)
```

기록은 브라우저의 `localStorage`에만 저장돼요. 다른 기기와 공유되지 않아요.
