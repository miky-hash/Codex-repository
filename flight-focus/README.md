# 포커스 에어 (Focus Air)

FocusFlight처럼 **집중 시간을 비행으로 바꿔 주는** 웹 앱이에요.
하고 싶은 집중 시간을 적으면 그 시간에 가까운 실제 항공편을 골라 주고,
탑승권을 찢고 탑승하면 지구본 위에서 비행기가 목적지로 날아가요.

## 실행 방법

설치할 것이 없어요. `flight-focus/index.html` 파일을 브라우저로 열면 됩니다.
(글꼴만 인터넷에서 불러오고, 지도와 코드는 모두 폴더 안에 있어서 오프라인에서도 동작해요.)

## 흐름

지구본은 계속 떠 있고, 단계가 바뀔 때마다 흰 박스가 모양을 바꾸며 움직이고 지구본도 자리를 옮겨요.
지구본은 **NASA 위성 사진**(블루 마블)을 입힌 공이고, 확대하면 1:50m 해안선·국경선이 선명하게 덧그려져요.
한 손가락으로 끌어서 돌리고, 두 손가락(핀치)·마우스 휠·+/− 버튼으로 최대 약 300배까지 확대해요.
목록에서 고르는 곳(시간·출발지·기종)은 모두 위아래로 굴리는 **룰렛 휠**이고, 굴리는 즉시 값이 바뀌어요.
버튼·토글·글자·창이 바뀔 때는 모두 짧은 움직임(모션)이 있어요.

0. **처음 화면**: 지구본 위에 공항 칩, 인사말과 현재 위치, 오늘 집중 시간·연속 집중일.
   고른 공항만 노란색이에요. 다른 공항을 누르면 지구본이 그쪽으로 돌고 그 공항이 노랗게 바뀌어요.
   아래 **여정 시작**(또는 "GMP에서 여정 시작")을 누르면 "○○ 공항에서 여정을 시작하시겠습니까?"를 물어요.
1. **소요 시간**: `( 1 )h ( 30 )m` 칸 중 하나를 누르면 룰렛 휠이 펼쳐지고, 굴려서 시간(0~15)·분(5분 단위)을 정해요. 빠른 선택 25분·50분·1:30·2:30·4:00.
2. **출발지·도착지**: 왼쪽 지구본에 항로가 그려지고, 오른쪽에서 출발지(A, 휠)와 도착지(B)를 골라요.
   도착지는 한 줄에 하나씩 "딱 맞는 항공편(±10분) / 조금 차이 나는 항공편(±45분) / 그 밖의 항공편(더 보기)"으로 묶여 있어요.
   *실제 비행시간* 또는 *내 시간* 중 하나로 날 수 있고, 기종도 휠로 골라요(잠긴 기종은 자물쇠 표시). **GO!**
   위쪽 설정과 목록 사이의 짧은 막대를 위로 밀면(또는 누르면) 위쪽이 한 줄 요약으로 접히고 목록이 넓어져요.
3. **과목**: 아래에서 올라오는 시트에서 공부·국어·수학·영어·과학·사회·한국사·기타(직접 입력) 중 선택.
4. **탑승권**: `Flight time / Subject / Gate / Boarding / Arrival / Aircraft / Distance / Date`.
   **절취선을 손가락으로 따라 긋거나**(가로 80% 이상), 바코드를 아래로 끌거나, **탑승하기**를 누르면 찢어져요.
   찢긴 조각은 떨어지고, 남은 탑승권은 절취선에서 곧은 직선(아래 꼭짓점 두 개)으로 끝나요. 약 2초 뒤 천천히 비행 화면으로 넘어가요.
5. **비행**: 지구본이 화면 전체로 펼쳐지고 `Gate → Takeoff → Cruise → Descent → Landing` 단계가 바뀌어요.
   단계마다 기내 차임(딩-동)과 **한국어 → 영어 기내 방송**이 나와요. 기장 방송은 낮고 차분하게, 승무원 방송은 밝게 읽고,
   방송하는 동안 엔진 소음이 작아져요. 남은 시간·남은 거리·고도·대지 속도. 일시정지는 없고 "비행 중단"은 회항으로 기록.
6. **도착 / 회항**: 도장, 집중 시간, 마일리지, 연속 집중일, 새 기종 해금, 환승 대기(쉬는 시간) 타이머.
7. **로그북**(처음 화면 오른쪽 위): 누적 기록, 과목별 집중 시간, 격납고, 방문한 도시, 전체 비행 기록.

도착한 공항이 **현재 위치**가 되어 다음 여정은 거기서 출발해요.
새로고침하거나 창을 닫았다 열어도 비행은 이어져요(종료 시각 기준으로 계산).

## 규칙

| 항목 | 규칙 |
| --- | --- |
| 실제 비행시간 | 40분(지상 이동·이착륙) + 대권 거리 ÷ 780km/h, 5분 단위 반올림 |
| 속도 | 단계별로 바뀌고, 순항 중에는 바람처럼 조금씩 오르내림. 위치는 이 속도를 적분해서 계산하고, 정확히 정해진 시간에 도착하도록 맞춤 |
| 마일리지 | 비행한 거리(km) × 0.621 |
| 연속 집중일 | 하루 한 번 이상 착륙 성공. 자정을 넘긴 비행은 착륙한 날로 셈 |
| 기종 해금 | A220-300(기본) → A321neo 1,000mi → 787-9 5,000mi → A350-900 15,000mi → 777-300ER 30,000mi → A380-800 60,000mi |

예) 인천→나리타 약 1,258km → 실제 비행시간 02:15

## 파일 구조

```
flight-focus/
├── index.html      화면 구조
├── style.css       디자인 (라이트/다크 모드)
├── app.js          비행 프로필, 지구본, 타이머, 기록 등 앱 로직
├── airports.js     공항 55곳 (IATA 코드, 영어 이름, 위도·경도)
├── world.js        세계 육지 (Natural Earth 1:110m, 퍼블릭 도메인) — 위성 사진을 못 쓸 때
├── world50.js      해안선·국경선 (Natural Earth 1:50m, 퍼블릭 도메인) — 확대했을 때
├── earth-texture.js 위성 사진 (NASA Blue Marble 4096×2048, 퍼블릭 도메인)
└── vendor/         d3-array, d3-geo (ISC 라이선스)
```

기록은 브라우저의 `localStorage`에만 저장돼요. 다른 기기와 공유되지 않아요.
