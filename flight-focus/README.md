# 포커스 에어 (Focus Air)

FocusFlight처럼 **집중 시간을 비행으로 바꿔 주는** 웹 앱이에요.
하고 싶은 집중 시간을 적으면 그 시간에 가까운 실제 항공편을 골라 주고,
탑승권을 찢고 탑승하면 지구본 위에서 비행기가 목적지로 날아가요.

## 실행 방법

- **실제 지도까지 쓰려면: GitHub Pages 주소로 열기 (추천)**
  1. 저장소 **Settings → Pages → Build and deployment → Source**를 **GitHub Actions**로 바꿔요.
  2. 이 작업이 `main` 브랜치에 합쳐지면 `.github/workflows/pages.yml`이 자동으로 배포해요.
  3. 주소는 `https://<아이디>.github.io/<저장소 이름>/` 이에요 (Settings → Pages에 표시돼요).
- **그냥 열기:** `flight-focus/index.html`을 브라우저로 열어도 돼요. 인터넷 지도에 닿지 않는 곳(예: Claude 미리보기)에서는
  자동으로 내장 지구본(NASA 위성 사진 / 단색 지도)을 써요.

## 지도 종류

오른쪽(또는 왼쪽) 아래의 **겹친 종이 버튼**을 누르면 지도 종류를 고를 수 있어요.

| 종류 | 인터넷 지도 (GitHub Pages 등) | 내장 지구본 (인터넷 지도를 못 쓸 때) |
| --- | --- | --- |
| 일반 | 도로·지명·국경이 있는 일반 지도 (OpenFreeMap, OpenStreetMap 데이터, 한국어 지명 우선) | 단색 지도 |
| 위성 | 위성 사진 + 지명 (Esri World Imagery) | NASA Blue Marble 위성 사진 |
| 지형 | 일반 지도 + 산 그림자(음영기복, AWS 지형 데이터) | 단색 지도 |

인터넷 지도는 MapLibre GL JS로 그리고, 앱의 지구본 움직임(단계 전환·확대·비행 추적)에 맞춰 카메라를 옮겨요.
위성 사진(Esri)은 개인·비상업 용도로 쓰는 것을 전제로 했어요. 상업적으로 배포할 때는 이용 약관을 다시 확인하세요.

## 흐름

지구본은 계속 떠 있고, 단계가 바뀔 때마다 흰 박스가 모양을 바꾸며 움직이고 지구본도 자리를 옮겨요.
지구본은 **NASA 위성 사진**(블루 마블)을 입힌 공이고, 확대하면 1:50m 해안선·국경선이 선명하게 덧그려져요.
한 손가락으로 끌어서 돌리고, 두 손가락(핀치)·마우스 휠·+/− 버튼으로 최대 약 300배까지 확대해요.
목록에서 고르는 곳(시간·출발지·기종)은 모두 위아래로 굴리는 **룰렛 휠**이고, 굴리는 즉시 값이 바뀌어요.
버튼·토글·글자·창이 바뀔 때는 모두 짧은 움직임(모션)이 있어요.

0. **처음 화면**: 지구본 위에 공항 칩(전 세계 291곳), 인사말과 위치, 오늘 집중 시간·연속 집중일.
   고른 공항만 노란색이에요. 다른 공항을 누르면 지구본이 그쪽으로 돌고, 그 공항이 노랗게 바뀌고, 왼쪽 위 위치도 바뀌어요.
   아래 버튼에는 항상 "인천(ICN)에서 여정 시작"처럼 이름과 코드가 나오고, 누르면 "○○ 공항에서 여정을 시작하시겠습니까?"를 물어요.
1. **소요 시간**: `( 1 )h ( 30 )m` 칸 중 하나를 누르면 룰렛 휠이 펼쳐지고, 굴려서 시간(0~15)·분(5분 단위)을 정해요. 빠른 선택 25분·50분·1:30·2:30·4:00.
   0시간 0분이면 다음 버튼이 회색으로 바뀌어 넘어갈 수 없어요.
2. **출발지·도착지**: 왼쪽 지구본에 항로가 그려지고, 오른쪽에서 출발지(A, 휠)와 도착지(B)를 골라요.
   도착지는 한 줄에 하나씩 "딱 맞는 항공편(±10분) / 조금 차이 나는 항공편(±45분) / 그 밖의 항공편(더 보기)"으로 묶여 있어요.
   *실제 비행시간* 또는 *내 시간* 중 하나로 날 수 있고, 기종도 휠로 골라요(잠긴 기종은 자물쇠 표시). **GO!**
   위쪽 설정과 목록 사이의 짧은 막대를 위로 밀면(또는 누르면) 위쪽이 한 줄 요약으로 접히고 목록이 넓어져요.
   **검색**: 출발지 휠을 펼치면 위에 검색창이 있고, 도착지 목록 위에도 검색창이 있어요. 도시 이름(도쿄), 영어(tokyo),
   공항 코드(NRT), 나라(일본), 한글 초성(ㄷㅋ)으로 찾을 수 있어요. Enter를 누르면 첫 결과를 고르고, 검색 중에는 결과 공항이 지구본에도 표시돼요.
   출발지이거나 너무 가까워서(60km 미만) 고를 수 없는 공항을 찾으면 이유를 알려 줘요.
3. **과목**: 아래에서 올라오는 시트에서 공부·국어·수학·영어·과학·사회·한국사·기타(직접 입력) 중 선택.
4. **탑승권**: `Flight time / Subject / Gate / Boarding / Arrival / Aircraft / Distance / Date`.
   **절취선을 손가락으로 따라 그으면 그은 만큼 실제로 찢어져요.** 찢긴 곳은 종이 결처럼 들쭉날쭉하게 벌어지고,
   한쪽 끝부터 찢으면 찢긴 쪽이 아래로 처지며 틈이 V자로 벌어져요. 찢을 때 '지직' 소리가 나요.
   손을 떼도 찢긴 곳은 그대로 남아서 이어서 찢을 수 있고, 가로 80%를 넘기면 나머지가 저절로 찢어져요.
   바코드를 아래로 끌어내리거나 **탑승하기**를 눌러도 돼요(버튼은 왼쪽부터 빠르게 찢어짐).
   찢긴 조각은 떨어지고, 남은 탑승권은 절취선에서 곧은 직선(아래 꼭짓점 두 개)으로 끝나요. 잠시 뒤 천천히 비행 화면으로 넘어가요.
5. **비행**: 지구본이 화면 전체로 펼쳐지고 `Gate → Takeoff → Cruise → Descent → Landing` 단계가 바뀌어요.
   위쪽 단계 막대는 지난 만큼 검게 차오르고, 지금 단계(노란 칸)에는 다음 단계까지 남은 시간이 나와요.
   단계마다 기내 차임(딩-동)과 **영어 기내 방송**이 나와요(화면에는 한국어 번역도 함께). 기장 방송은 낮고 차분하게,
   승무원 방송은 밝게 읽고, 방송하는 동안 엔진 소음이 작아져요. 비행기는 기종별 실제 비율로 그리고, 높이 날수록 그림자가 멀어져요.
   - 비행 창은 스크롤되지 않아요. 화면이 작으면 한국어 번역 → 방송 칸 → 비행 정보 순으로 알아서 숨겨요.
   - **창 줄이기**: 비행 창 오른쪽 위 버튼을 누르면 남은 시간·남은 거리·단계·진행 막대·일시정지만 있는 작은 창이 돼요.
   - **일시정지**: 멈춘 동안은 남은 시간·비행기·단계가 그대로이고, 멈춘 만큼 도착이 늦어져요. 집중 시간에도 들어가지 않아요.
   - **지도 직접 움직이기**: 비행 중에도 지도를 끌어서 옮기고 확대할 수 있어요. 그러면 비행기 따라가기가 꺼지고,
     오른쪽 **화살표 버튼**(지도 앱의 내 위치 버튼처럼)을 누르면 다시 비행기를 따라가요. 지구 전체가 보일 때까지 축소할 수 있어요.
   - 확대해도 비행기가 끊기지 않게, 비행기가 화면에서 빨리 움직일 때는 매 프레임 그려요.
   - **알림**: 단계가 바뀔 때, 절반이 지났을 때, 착륙 5분 전에 위쪽에 알림 띠가 떠요. 탑승할 때 기기 알림을 허락하면
     다른 앱에 가 있거나 화면이 꺼졌을 때도 기기 알림으로 알려 줘요(GitHub Pages 같은 https 주소에서, 브라우저가 허락하는 만큼).
   - "비행 중단"은 회항으로 기록돼요.
6. **도착 / 회항**: 도장, 집중 시간, 마일리지, 연속 집중일, 새 기종 해금, 환승 대기(쉬는 시간) 타이머.
7. **로그북**(처음 화면 오른쪽 위): 누적 기록, 과목별 집중 시간, 격납고, 방문한 도시, 전체 비행 기록.

도착한 공항이 **현재 위치**가 되어 다음 여정은 거기서 출발해요.
새로고침하거나 창을 닫았다 열어도 비행은 이어져요(종료 시각 기준으로 계산).

## 규칙

| 항목 | 규칙 |
| --- | --- |
| 실제 비행시간 | 40분(지상 이동·이착륙) + 대권 거리 ÷ 780km/h, 5분 단위 반올림 |
| 속도 | 단계별로 바뀌고, 순항 중에는 바람처럼 조금씩 오르내림. 위치는 이 속도를 적분해서 계산하고, 정확히 정해진 시간에 도착하도록 맞춤 |
| 마일리지 | **집중한 시간에 비례**: 1분에 8마일(여객기 평균 속도 약 780km/h ≈ 분당 8마일). 거리와 상관없어요. **정한 비행시간의 절반이 지나야** 쌓이기 시작하고, 절반 전에 중단하면 0마일 |
| 일시정지 | 멈춘 시간은 집중 시간·진행률에서 빠지고, 도착 예정 시각이 그만큼 늦어져요 |
| 연속 집중일 | 하루 한 번 이상 착륙 성공. 자정을 넘긴 비행은 착륙한 날로 셈 |
| 기종 해금 | A220-300(기본) → A321neo 1,000mi → 787-9 5,000mi → A350-900 15,000mi → 777-300ER 30,000mi → A380-800 60,000mi |

예) 인천→나리타 약 1,258km → 실제 비행시간 02:15

## 파일 구조

```
flight-focus/
├── index.html      화면 구조
├── style.css       디자인 (라이트/다크 모드)
├── app.js          비행 프로필, 지구본, 타이머, 기록 등 앱 로직
├── airports.js     공항 291곳 (IATA 코드, 영어 이름, 위도·경도)
├── sw.js           기기 알림용 서비스 워커 (캐시는 안 함)
├── DEVLOG.md       개발 기록 (요청과 반영, 해결한 문제, 구조)
├── world.js        세계 육지 (Natural Earth 1:110m, 퍼블릭 도메인) — 위성 사진을 못 쓸 때
├── world50.js      해안선·국경선 (Natural Earth 1:50m, 퍼블릭 도메인) — 확대했을 때
├── earth-texture.js 위성 사진 (NASA Blue Marble 4096×2048, 퍼블릭 도메인)
├── planes/         기종별 비행기 그림을 넣는 곳 (넣으면 자동으로 사용)
├── sounds/         실제 기내 소음 녹음을 넣는 곳 (cabin.mp3 등)
└── vendor/         d3-array, d3-geo (ISC), MapLibre GL JS (BSD-3)
```

기록은 브라우저의 `localStorage`에만 저장돼요. 다른 기기와 공유되지 않아요.

## 비행기 그림 · 기내 소음

- `planes/A220.png` … `planes/A380.png`: 기종별 비행기 그림(위에서 본 모습, 배경 투명, 512px). 다른 그림으로 바꾸려면 같은 이름으로 덮어쓰면 돼요.
- `sounds/cabin.wav`: 실제 기내 소음 녹음. 앞뒤의 소리가 커지고 작아지는 부분을 잘라 내고 끝과 처음을 겹쳐서(크로스페이드)
  끊김 없이 반복되게 만든 26초짜리 파일이에요(스테레오, 32kHz).

웹에서는 앱이 꺼져 있거나 화면이 잠겨 있으면 브라우저가 스크립트를 멈출 수 있어서, 그동안의 알림은 늦게 오거나 오지 않을 수 있어요.
