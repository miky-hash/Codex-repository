# 기내 소음 넣는 곳

`cabin.mp3`(또는 `cabin.ogg`, `cabin.m4a`, `cabin.wav`)를 넣으면 "기내 소음" 버튼이 이 녹음을 끊김 없이 반복해서 틀어요.
없으면 앱이 합성한 엔진 소리를 써요.

- 길이 30초~2분, 처음과 끝이 자연스럽게 이어지는 녹음이 좋아요.
- 저작권: CC0(퍼블릭 도메인)이나 출처 표시만 하면 되는 녹음을 쓰고, 출처는 이 파일 아래에 적어 두세요.

출처:

현재 포함된 `cabin.mp3`는 기존 사용자 제공 `cabin.wav`를 128kbps MP3로 압축한 파일이에요.
길이 25.9초·32kHz·스테레오는 유지하며, 파일 크기는 3,315,244바이트에서 415,917바이트로 줄였어요.
원본 WAV는 Git 변경 이력에 남아 있어요.
